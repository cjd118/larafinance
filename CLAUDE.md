ABOUT THE PROJECT

This is a Laravel project using Laravel conventions. 

RUNNING THE PROJECT

The project uses Laravel Sail. 

If Laravel Sail is not running it can be started with `./vendor/bin/sail up -d`.

RUNNING THE TESTS

`./vendor/bin/sail test` assuming Laravel Sail is running. 

GIT COMMIT FORMAT

New features to be prefixed with feat: 
Fixes/bugs to be prefixed with fix: 
Test changes only to be prefixed with test: 
Dev/linting/DX changes to be prefixed with dev:
